# Challenge 10
Mission to Mars.

In this project, I enhanced an existing web application by adding more polished, dynamic content. I identified a scraping-friendly website that hosted high-quality images of Mars’s hemispheres and used BeautifulSoup and Splinter to scrape the full-resolution hemisphere images along with their titles.

I then stored the collected data in a MongoDB database and integrated it into the web application so the images and metadata could be displayed dynamically. Finally, I updated the application’s layout and design to properly showcase all four hemisphere images, improving both the functionality and overall user experience.
